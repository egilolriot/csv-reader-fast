A faster drop-in for make.fun's own csv-reader 1.0.0: it answers exactly as csv-reader does on every broken CSV input, but reads with native indexOf jumps and one slice per field instead of one character at a time, so it runs in a fraction of the CPU time.

## Run it

```sh
node main.ts
```
